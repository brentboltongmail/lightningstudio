# LightningStudio

A suite of integrated web-based studio tools.

## Included Tools

- **3DEditor**: A modern, fast, web-based 3D editor to interactively clip and modify `.glb` models.
- **SoundEditor**: A web-based audio editing suite.
- **iOS Controller** (`ios-controller/`): Electron app to mirror an iPhone over USB, inject taps/swipes via WebDriverAgent, and run macros. See [ios-controller/README.md](ios-controller/README.md) for the macOS setup roadmap.
