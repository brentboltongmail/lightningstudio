# LightningStudio

A suite of integrated studio tools.

## Included Tools

- **3DEditor**: A modern, fast, web-based 3D editor to interactively clip and modify `.glb` models.
- **SoundEditor**: A web-based audio editing suite.
- **Lightning Macro**: Desktop mouse/keyboard macro recorder (Python + pywebview). See [`lightning-macro/`](lightning-macro/).
